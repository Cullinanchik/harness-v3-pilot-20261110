# Решение по дизайну и повторному использованию

Визуальный дизайн не требуется: изменения ограничены Python API, unittest и README. Новых экранов, компонентов UI, 3D-моделей, текстур и анимаций нет; экспорт Claude Design и dev-preview не нужны. `design.json.required=false`, `reuse=[]` означает отсутствие визуальных материалов для повторного использования.

Существующий модуль retry_policy.py, механизм unittest и структура README используются повторно; constant_delay сохраняется относительно baseline 067c6b554b31cd8929bc58bd4402ab3fcd5d9aae. needs_uat=false: пользовательский результат выражается числовыми ответами API и проверяется автоматически. Независимые согласование плана и приёмка результата владельцем в Telegram остаются обязательными; отсутствие UAT их не заменяет.
